Privacy Policy

Effective Date: October 29, 2026 · Standalone Open Source Software

1. Summary & Core Principles

CodeExplorer (CLI binary ce and the VS Code Extension code-explorer-vscode) is designed from the ground up as a 100% local-first, privacy-by-design architecture intelligence engine.

  • Zero Telemetry: CodeExplorer does not collect, record, or transmit usage statistics, crash dumps, or telemetry.
  • Zero Code Transmission: Your source code, AST, tokens, git history, and architecture graphs never leave your local machine or your CI/CD runner.
  • Local Database: All parsed architecture data is stored in a local SQLite database (.codeexplorer/codeexplorer.db) within your project repository.
  • No User Accounts: We do not require registration, accounts, or authentication to use CodeExplorer.

2. Website (code-explorer.app)

The website code-explorer.app is a static documentation and download portal hosted on an isolated server.

Standard web server access logs (client IP address, user-agent, requested URL, and timestamp) are processed strictly for operational security, DDOS mitigation, and anonymous aggregate visitor counts. No advertising cookies, third-party trackers, or personal tracking scripts are loaded on this website.

3. Local Architecture Engine Execution

When you execute ce scan, ce map, or ce gate, or when you interact with the VS Code extension or MCP server:

  • The analysis executes exclusively on your CPU using local Roslyn/Tree-sitter parsers.
  • No external network requests are made during scanning or invariant checking.
  • MCP agent interactions (Claude Code, Cursor, Copilot) are mediated locally via standard input/output (stdio) with your local client.

4. Open Source Transparency & License

CodeExplorer is free and open-source software released under the MIT License. The entire source code is publicly inspectable and auditable on GitHub.

5. Contact

If you have questions regarding this privacy policy or security practices, you can open an issue on the official GitHub repository at github.com/vmikhailov/code-explorer/issues.
