CodeExplorer ce Live architecture for you, your agent and your CI

A healthy codebase today and tomorrow

CodeExplorer is formulated specially for monorepos and multi-service systems.

Keeping a healthy architecture matters. The balance between services, queues and tables decides how fast your team, and your AI agent, can change the code safely.

CodeExplorer compiles your repositories into one local graph, so everyone reads the same map. It lives in .codeexplorer/graph.db, next to your code.

Benefits and key ingredients

  • Formulated to keep you oriented. Live diagrams of services, APIs, queues and tables, rebuilt from code on every scan.

  • Supports your agent's memory with ~7.0× fewer input tokens per audit.*

    *Compared with codebase-memory-mcp on twentyhq/twenty, same model and prompt.

  • Healthy CI thanks to a balance of architecture rules and a baseline ratchet that blocks only new violations.

  • Graph The number one ingredient. Five layers, from files and projects up to services and tables.

No cloud, no telemetry, no account and no vendor lock-in

CodeExplorer (ce). Complete local architecture graph for polyglot and multi-service repositories, with a high content of Cypher.

Composition: C# and .NET (ASP.NET, gRPC, Wolverine, Hangfire, MassTransit, EF Core, Dapper), Java (Spring Boot, Quarkus, Micronaut, Dubbo, MyBatis, jOOQ, Hibernate), Kotlin (Spring, Ktor, Exposed, Room, SQLDelight, Retrofit), TypeScript and JavaScript (NestJS, Next.js, tRPC, Hono, Kysely, TypeORM, Prisma, BullMQ), Go (Gin, Fiber, gRPC-Gateway, Watermill, GORM, sqlx, Ent), Python (FastAPI, Litestar, Django, Celery, Dramatiq, SQLAlchemy, Temporal), Rust (Axum, Actix Web, Tonic, SQLx, SeaORM, Diesel), PHP (Symfony, Laravel, Zend Framework 1, Doctrine, Nette DB, PDO), Perl (DBI, LWP::UserAgent, CPAN), ColdFusion (CFML, cfquery lineage, cfhttp), SQL (PostgreSQL, T-SQL, MySQL, SQLite, ClickHouse, BigQuery), Terraform and HCL (modules, Terragrunt, AWS, GCP and Azure resources).

Layers: physical files, projects and packages, syntax and dataflow, semantic architecture (workloads, endpoints, databases, tables, topics), logical domains and bounded contexts.

Storage: keep .codeexplorer/graph.db in the repository root. Rescan after changes: only modified files are parsed again.

Best before: never goes stale, rebuilt from code on every scan.

Manufacturer: Viacheslav Mikhailov. Distributed through Homebrew, NuGet, the VS Code Marketplace and Open VSX under the MIT license.
