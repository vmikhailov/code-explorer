Rules that fail the build, not the review.

Write an architectural rule once as a Cypher query. CI checks it on every pull request, whoever wrote the code.

# .codeexplorer/gates/domain-purity.yaml
id: ARCH-001
name: Domain must not reference Infrastructure
severity: error
query: |
  MATCH (d:Class)-[:DEPENDS_ON|CALLS]->(inf:Class)
  WHERE d.namespace CONTAINS ".Domain"
    AND inf.namespace CONTAINS ".Infrastructure"
  RETURN d.fullName, inf.fullName

  3. Block anything newA net-new violation fails the PR with exit code 1.
  4. Tighten as it healsFix a legacy violation and the ceiling drops for good.
