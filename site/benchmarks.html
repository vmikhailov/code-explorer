Benchmarks: AI agents & graph engines.

We run two distinct types of benchmarks:
1. End-to-End AI Agent Workflows (measuring how much time, tokens, and missed dependencies a graph saves an LLM on real tasks).
2. Graph Engine Head-to-Head (measuring cold scan speed, RAM, query latency, and extraction recall without an LLM).

1. AI agents in real tasks (time, tokens & completeness).

Identical model (Gemini 3.8 Flash), identical prompt, same pinned repository commit. Measures how fast an autonomous agent finishes a multi-hop architecture audit, how many tokens it burns, and whether it finds every affected service and table.
