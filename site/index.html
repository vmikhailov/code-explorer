      (target:Function {name: "ChargeAsync"})

       length(path) AS Hops
ORDER BY Hops ASC
LIMIT 10

Semantic Invariant Gates: architectural checks in CI.

Linters inspect one file at a time. Semantic Invariant Gates (SIG) check dependencies and dataflow across the full 5-layer graph, with a SHA-256 baseline ratchet so legacy violations stay frozen while new ones fail the build.

Architecture Gate Packs
.codeexplorer/gates/domain-purity.yaml 
id: SIG-CA-B-001
name: Domain Layer Must Not Reference Infrastructure
severity: Error
target: "{inf.name}"
message: "Domain type '{d.name}' references infrastructure type '{inf.name}'"
query: |-
  MATCH (d:Type)-[:DEPENDS_ON|INHERITS|IMPLEMENTS]->(inf:Type)
  WHERE d.file_path CONTAINS "/Domain/"
    AND (inf.file_path CONTAINS "/Infrastructure/"
      OR inf.symbol CONTAINS "DbContext")
  RETURN d, inf

Blocks any type inside a Domain module from referencing Infrastructure or EF Core types.

  1. Author YAML rules Place invariant rules in .codeexplorer/gates/*.yaml or scaffold defaults with ce gate init.
  2. Snapshot brownfield debt Run ce gate ratchet --update to record SHA-256 fingerprints of existing legacy violations in .codeexplorer/baselines/*.json.
  3. Block net-new violations ce gate check passes when only baselined debt is present and exits with code 1 when a PR introduces a new violation.
  4. Auto-tighten as code heals Whenever a baselined violation is fixed, re-running the ratchet lowers the ceiling so resolved debt cannot return.

name: Architecture Invariant Gates
on: [pull_request]

jobs:
  invariant-gates:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install CodeExplorer CLI
        run: curl -fsSL https://code-explorer.app/install.sh | sh
      - name: Build Graph & Verify Invariant Gates
        run: |
          ~/.local/bin/ce scan
          ~/.local/bin/ce gate check --format sarif > results.sarif
