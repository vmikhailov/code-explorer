Embedded Query Engine

Test real architectural inquiries against the graph database. Fast, declarative, and structured.

// Find all downstream services impacted by OrderPlaced event
MATCH (p:Service {name: 'OrderService'})-[r:EMITS]->(e:DomainEvent)
MATCH (e)<-[:SUBSCRIBES]-(downstream:Service)
OPTIONAL MATCH (downstream)-[:WRITES_TO]->(tbl:Table)
RETURN
    p.name AS Producer,
    e.name AS EventName,
    downstream.name AS Consumer,
    tbl.name AS TargetTable
ORDER BY Consumer

Architecture Governance & CI/CD

Semantic Invariant Gates (SIG)

Transform openCypher queries from passive codebase observation into active, automated architectural guardrails. Enforce layer boundaries, eliminate cyclic package coupling, block breaking contract changes, and freeze legacy debt with monotonic ratchets directly in CI/CD and AI agent loops.

Dimension: Boundaries

Clean Architecture & Purity

Enforce strict hexagonal and DDD bounded context isolation. Prohibit Domain and Core layers from referencing Web, UI, or direct persistence drivers.

:Library -[:DEPENDS_ON]-> :Package
Dimension: Topology

Cyclic Shield & DAG Ranking

Detect direct and transitive circular references across modules (A ➔ B ➔ A). Preserve strict acyclic DAG project compilation structures before merge.

(a:Project)-[:DEPENDS_ON*2..6]->(a)
Dimension: Contracts

API & Schema Integrity

Detect breaking API signature alterations, unversioned route drift, and direct leaking of internal ORM entity models through public REST/gRPC response endpoints.

:Endpoint -[:RETURNS]-> :Entity
Dimension: Resilience

Direct Egress & Coupling

Catch controller handlers issuing raw SQL queries directly against physical database tables, bypassing application service layers and transaction managers.

:Endpoint -[:CALLS*]-> :Query

            Zero Tolerance for New Debt
          

          

            Monotonic Ratchet Engine
          

          

            Architectural rules shouldn't require resolving 500 legacy violations before being introduced to CI.
            CodeExplorer freezes existing violations into stable SHA-256 baseline snapshots — tolerating legacy debt while strictly failing builds on any newly introduced violation.
          


          

            

              
1

              

                
Declare Invariant Contract

                
Write an openCypher rule in .codeexplorer/gates/*.yaml matching forbidden patterns with remediation instructions.

              

            

            

              
2

              

                
Freeze Baseline Snapshot

                
ce gate ratchet --update captures structural hashes of existing debt into baseline JSON.

              

            

            

              
3

              

                
Enforce in CI/CD & AI Agent Loops

                
ce gate check passes legacy debt ([TOLERATED]) but immediately rejects new debt ([FAIL]).

              

            

            

              
4

              

                
Monotonic Ratchet Descent

                
As technical debt is refactored away, baseline snapshots automatically lower the ceiling. Debt cannot increase.

              

            

          

        


        

          

            .github/workflows/architecture-gates.yml
            
          

          
# Pull Request Architectural Guardrail
name: Architectural Invariant Gates
on: [pull_request]

jobs:
  verify-architecture:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install CodeExplorer CLI
        run: curl -fsSL https://raw.githubusercontent.com/vmikhailov/code-explorer/main/cli/scripts/install.sh | bash
      - name: Scan AST & Compile SQLite Graph
        run: ce scan
      - name: Evaluate Semantic Invariant Gates
        run: ce gate check --fail-on-new
      # Exits with non-zero exit code if PR introduces any new architecture violations

          Semantic Structure
        

        
5-Layer Decoupled Graph Ontology

        

          Every entity in your codebase is represented across five decoupled layers, connecting physical files to business domain concepts.
        

      


      

        

          
LAYER 5

          
Late-Bound Layer

          
Cross-project HTTP routes, message broker events, CQRS pipelines (MediatR/Spring), and interface implementations resolved via post-index graph passes.

          
:Channel, :Pipeline, :EventFlow

        


        

          
LAYER 4

          
Semantic Layer

          
Inbound REST/gRPC/GraphQL endpoints, security roles, ORM entities mapped to physical database tables, and external egress HTTP clients.

          
:EntryPoint, :Table, :Policy

        


        

          
LAYER 3

          
Syntactic Layer

          
Pure Tree-sitter AST declarations: classes, records, interfaces, methods, functions, structs, fields, and direct intra-file invocations.

          
:Class, :Method, :Function

        


        

          
LAYER 2

          
Project Layer

          
Logical compilation units, internal project references, third-party NuGet/NPM/Go dependencies, and package boundary isolation.

          
:Project, :Package, :Module

        


        

          
LAYER 1

          
Physical Layer

          
Workspace root, file tree, physical paths, configuration files (.env, appsettings.json, pom.xml, go.mod), and Git repository metadata.

          
:Workspace, :Folder, :File

          Quick Start
        

        
Install in Seconds

        

          Single self-contained binaries for macOS, Linux, and Windows. No SDK required.
        

      


      

        

          
          
          
          
          
        


        
        

          

            brew install vmikhailov/tap/ce
            
          

          
Installs the ce binary directly into your PATH with automatic shell completions.

        


        
        

          

            code --install-extension vmikhailov.code-explorer-vscode
            
          

          
Bundles pre-compiled native binaries for all platforms; no external CLI setup needed.

        


        
        

          

            irm https://raw.githubusercontent.com/vmikhailov/code-explorer/main/cli/scripts/install.ps1 | iex
            
          

          
Downloads standalone self-contained ce.exe and registers in Windows User PATH.

        


        
        

          

            curl -fsSL https://raw.githubusercontent.com/vmikhailov/code-explorer/main/cli/scripts/install.sh | bash
            
          

          
Automated architecture detection (x64 / ARM64) and direct installation to ~/.local/bin.

        


        
        

          

            dotnet tool install -g CodeExplorer.Cli
            
          

          
For developers with .NET 10 SDK already installed.

        


        
        

          

            
ce init

            
Initialize a .codeexplorer workspace configuration in current repository.

          

          

            
ce scan

            
Run AST visitors across all source files and compile the SQLite graph.

          

          

            
ce query "MATCH..."

            
Execute an arbitrary Cypher query and output structured JSON or table.

          

          

            
ce export -f mermaid

            
Export macro architecture or C4 container diagrams into Mermaid syntax.

          

          

            
ce mcp --port 5000

            
Start Model Context Protocol server in HTTP/SSE streaming or stdio mode.

          

          

            
ce schema

            
Inspect active ontology node labels, relationships, and property dictionary.

          

          

            
ce gate check

            
Evaluate semantic invariant gates against SQLite graph; exits non-zero on new debt.

          

          

            
ce gate ratchet --update

            
Freeze current violations into baseline snapshots, enforcing monotonic debt reduction.

          

          

            
ce gate violations -g <id>

            
Inspect, group by file, and export structured violation reports and remediation hints.
