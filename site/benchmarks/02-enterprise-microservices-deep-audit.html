Case Study 02: 324-service enterprise monorepo audit (ce vs. ripgrep).

Two identical Gemini Flash agents executed a 4-part cross-service architectural audit on a distributed microservices monorepo (324 microservices, 93 shared libraries, 33 workers, 13,782 source files): one using ripgrep + Python scripts + view_file, and one using CodeExplorer (ce callers & ce query).

Inspect Outputs & metrics.json See Public Equivalent on twentyhq/twenty (05)
Transparency note on repository access: This benchmark was run on a private production monorepo. Service, table, and topic names in the published outputs are anonymized 1-to-1 while preserving exact execution telemetry from transcript_full.jsonl. For a 100% public, non-anonymized equivalent on open-source code, see Case Study 05 (twentyhq/twenty) and Case Study 01 (code-explorer).
