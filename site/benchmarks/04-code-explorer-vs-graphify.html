1. Cold indexing & scalability across repository sizes.

On immich (3,205 files), both tools completed cleanly, with ce finishing 6.1× faster. On twenty (24,527 files), Graphify's Python AST & NetworkX pipeline stalled on a single CPU core in build_from_json and did not finish within the 45-minute timeout.

Metric Repo CodeExplorer (ce v1.75.0) Graphify (v0.9.104) Outcome
Cold Index Wall Time immich (3.2k files) 17.60 s (55.1 MB SQLite DB) 107.60 s (32.0 MB JSON / 52.3 MB dir) ce 6.11× faster
Cold Index Wall Time twenty (24.5k files) 147.33 s (784.0 MB SQLite DB) DNF (>2,740 s / >45.6 min timeout) ce >18.6× faster (Graphify timed out)

Methodological note on --code-only vs. LLM synthesis: Graphify also offers an optional LLM pass for extracting semantic / rationale nodes from Markdown docs, PDFs, and images. This benchmark evaluates deterministic static code extraction (--code-only) so that every result measures the indexer itself rather than an external LLM's token budget or non-deterministic sampling.

3. MCP server latency & feature trade-offs on immich.

Because Graphify loads graph.json into an in-memory Python NetworkX graph on startup, cold MCP initialization takes 3.68 seconds vs. 0.60 seconds for ce's SQLite engine.
