1. Cold indexing & scalability across repository sizes.

On immich (3,205 files), both tools completed cleanly, with ce finishing ~6.1× faster. On twenty (24,527 files), Graphify’s Python AST & NetworkX pipeline stalled on a single CPU core in build_from_json and did not finish within the 45-minute timeout.

Methodological note on --code-only vs LLM synthesis: Graphify also offers an optional LLM pass for extracting semantic / rationale nodes from Markdown docs, PDFs, and images. This benchmark evaluates deterministic static code extraction (--code-only) so that every result measures the indexer itself rather than an external LLM’s token budget or non-deterministic sampling.

3. MCP server latency & tool trade-offs on immich.

Because Graphify loads graph.json into an in-memory Python NetworkX graph on startup, cold MCP initialization takes ~3.7 seconds vs ~0.6 seconds for ce’s SQLite engine.

Queries & Matchers scripts/eval_ce_vs_graphify.py: Exact OpenCypher Queries (ce) & NetworkX Graph Extraction Rules (Graphify) 
# CodeExplorer (ce v1.75.0) OpenCypher Queries:
# C1 (Endpoints):
MATCH (e:Endpoint)-[:EXPOSED_BY]->(f:Function) RETURN f.file_path, f.start_line, f.name, e.http_method, e.route_template
# C2 (Outbound HTTP):
MATCH (ext:ExternalService)-[r:CALLED_BY]->(f:Function) WHERE COALESCE(ext.protocol, 'http') <> 'graphql' RETURN f.file_path, COALESCE(r.line, f.start_line), f.name, COALESCE(ext.url, ext.name)
# C3 & C8 (Queues / Topics):
MATCH (t:Topic)-[:PUBLISHED_BY]->(f:Function) RETURN f.file_path, f.start_line, f.name, t.name;
MATCH (t:Topic)-[:SUBSCRIBED_BY]->(m:Function) RETURN m.file_path, m.start_line, m.name, t.name
# C4 & C10 (ORM Tables & Schema):
MATCH (t:Table) OPTIONAL MATCH (t)-[:IMPLEMENTED_BY]->(ent:Type) RETURN COALESCE(ent.file_path, t.path), ent.start_line, COALESCE(ent.name, t.name), t.name
# C5 (Read/Write Lineage):
MATCH (q:Query)-[r:WRITES_TO|READS_FROM]->(t:Table) OPTIONAL MATCH (q)-[:ACCESSED_BY]->(f:Function) RETURN COALESCE(f.file_path, q.file_path), q.start_line, COALESCE(f.name, q.name), type(r), t.name
# C6 (Call Graph & DI Callers):
MATCH (caller:Function)-[:CALLS]->(callee:Function) WHERE callee.name IN [<target_methods>] OPTIONAL MATCH (enclosing:Function)-[:DECLARES]->(caller) RETURN caller.file_path, COALESCE(enclosing.start_line, caller.start_line), COALESCE(enclosing.name, caller.name), callee.name
# C7 (Inheritance & implements):
MATCH (c:Type)-[r:INHERITS_FROM|IMPLEMENTS]->(p) RETURN c.file_path, c.start_line, c.name, type(r), p.name

# ------------------------------------------------------------------------------
# Graphify (v0.9.104) graph.json Node & Link Extraction (eval_ce_vs_graphify.py):
# - Cold indexing command: `graphify index <repo_path> --code-only`
# - C6 (Call Graph): Links in `graph.json["links"]` where `relation == "calls"`, matching source function `(source_file, source_line, label)` and target method `.label.split(".")[-1]`.
# - C7 (Inheritance & implements): Links in `graph.json["links"]` where `relation in ("inherits", "implements")`, matching child class `(source_file, source_line, label)` and parent class/interface label.
