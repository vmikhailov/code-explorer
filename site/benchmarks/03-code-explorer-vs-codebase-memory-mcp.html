1. Cold indexing speed, disk size, and memory.

CodeExplorer was faster and produced a 5.1× smaller database on immich (3,205 files). On twenty (24,527 files), CBM completed cold indexing 1.52× faster with lower peak RAM because it extracts only Layer 1–3 AST and call edges, whereas ce also runs 250 Layer 4–5 framework, ORM, and queue analyzers.
