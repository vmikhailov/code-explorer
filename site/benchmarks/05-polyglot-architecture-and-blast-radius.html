1. What the agents had to solve on OrchardCore.

In a modular .NET monolith like OrchardCore, classes rarely implement root interfaces directly: they inherit through generic base classes (such as ContentPartDisplayDriver<TPart> or ContentHandlerBase) across [TBD ~180] separate .csproj modules.

Display Drivers & Content Handlers

Task 1

Find all classes implementing IDisplayDriver and IContentHandler (including indirect subclasses via generic base classes) across key content modules.

Tests transitive :INHERITS_FROM|IMPLEMENTS*1..5

Upstream Callers & Endpoints

Task 2

Trace production callers of core content management services across module boundaries up to the triggering Razor/MVC controller endpoints and background tasks.

Tests C# constructor DI resolution & :CALLS

Project Fan-In & YesSql Indexes

Task 3

Identify which modules depend on core abstractions and map document index providers to their underlying storage tables.

Tests :DEPENDS_ON & data lineage
