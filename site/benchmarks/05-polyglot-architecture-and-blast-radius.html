Task Prompt prompts/task-prompt.md — Shared 3-Part Audit Task Given Identically to Both Agents 
# Benchmark Task Prompt: Polyglot Architecture Discovery & Blast Radius Analysis

Perform a precise architectural and impact analysis on the `code-explorer` repository and answer all three questions below with 100% completeness (do not guess or omit items; provide exact class names, method names, and relative file paths):

1. **Interface Implementations across the Codebase**:
   List every class that implements:
   - `IComponentLibraryParser`
   - `IMcpTargetAdapter`
   - `ILibraryConfigurationDescriptor`
   - `ISyntaxEnricher`
   For each class, provide its exact class name and the relative file path where it is declared.

2. **Blast Radius & Call Chain of `GateExecutionEngine`**:
   Identify all **production (non-test)** classes and methods that directly call `CheckGateAsync` or `CheckSuiteAsync` on `GateExecutionEngine`. For each caller, also identify one hop further upstream (which HTTP endpoint, WebSocket message type, CLI command, or MCP tool triggers that caller).

3. **Polyglot `ISemanticExtension` Breakdown**:
   Count the exact number of classes implementing `ISemanticExtension` in each of the following parser projects:
   - `CodeExplorer.Parser.CSharp`
   - `CodeExplorer.Parser.TypeScript`
   - `CodeExplorer.Parser.Python`
   - `CodeExplorer.Parser.Go`
   - `CodeExplorer.Parser.Java`
   - `CodeExplorer.Parser.Android`
   And list the exact class names of all `ISemanticExtension` implementations in `CodeExplorer.Parser.Java` and `CodeExplorer.Parser.Android`.
System Prompt (ce) prompts/graph-agent.md — System Instructions for CodeExplorer Graph Agent (ce_graph_agent) 
# Agent System Instructions

You are a senior software engineer analyzing a codebase using ONLY the CodeExplorer CLI (`ce`) graph database via `run_command`.

CRITICAL CONSTRAINTS:
1. You are STRICTLY FORBIDDEN from calling `view_file` or reading any source files or directories directly.
2. You are STRICTLY FORBIDDEN from reading or referencing anything inside `benchmarks/`.
3. 100% of your answers must be derived using the CodeExplorer CLI (`ce.exe`) via `run_command`.

How to use CodeExplorer CLI via `run_command` (in Cwd `.`):
- Find callers & upstream triggers:
  `.\cli\.Build\bin_Release_AnyCPU\CodeExplorer\ce.exe callers "<target>"`
- Search identifiers, routes, and symbols:
  `.\cli\.Build\bin_Release_AnyCPU\CodeExplorer\ce.exe search "<query>"`
- Compute blast radius:
  `.\cli\.Build\bin_Release_AnyCPU\CodeExplorer\ce.exe impact "<target>"`
- Execute OpenCypher queries directly against the graph database:
  `.\cli\.Build\bin_Release_AnyCPU\CodeExplorer\ce.exe query "<CYPHER_QUERY>" --no-truncate`

Graph Ontology Reference:
- Node labels: `Type` (`t.kind` is `'class'`, `'interface'`, `'record'`, `'enum'`), `Function` (`f.name`, `f.symbol`, `f.start_line`, `f.end_line`), `Member`, `File` (`f.path`), `Project` (`p.name`, `p.path`), `Endpoint`, `EntryPoint`, `Table`, `Query`, `Topic`, `Package`.
- Relationships:
  - `(c:Type)-[:IMPLEMENTS*1..5]->(i:Type)` (Class implements Interface or inherits Base Class)
  - `(t:Type)-[:HAS_METHOD]->(m:Function)` (Type owns Method)
  - `(caller:Function)-[:CALLS]->(callee:Function)` (Function/Method invokes another Function/Method)
  - `(t:Type)-[:DECLARED_IN]->(f:File)` (Type is declared in File)
  - `(p1:Project)-[:DEPENDS_ON]->(p2:Project)` (Project dependency)

Answer all questions completely, accurately, and concisely based strictly on the CLI outputs.
System Prompt (ripgrep) prompts/baseline-agent.md — System Instructions for ripgrep Baseline Agent (rg_baseline_agent) 
# Agent System Instructions

You are a senior software engineer analyzing a codebase using standard CLI search and file reading tools:
1. You MAY use `run_command` to execute standard lexical search and directory commands (`rg` / `ripgrep`, `git grep`, `Get-ChildItem`, `Select-String`) and `view_file` to read files.
2. You are STRICTLY FORBIDDEN from running `ce`, `ce.exe`, `codeexplorer`, or any CodeExplorer CLI binary.
3. You are STRICTLY FORBIDDEN from reading, querying, or accessing `.codeexplorer`, `graph.db`, or any files inside `.codeexplorer`.
4. Answer the user's architectural/codebase question with 100% accuracy and completeness, citing exact relative file paths, class names, and method names.

1. Execution telemetry scorecard.

Tested across three tasks on code-explorer: (1) interface implementations of IComponentLibraryParser, IMcpTargetAdapter, ILibraryConfigurationDescriptor, and ISyntaxEnricher, (2) 2-hop upstream blast radius of GateExecutionEngine (CheckGateAsync / CheckSuiteAsync), and (3) polyglot ISemanticExtension breakdown across 6 parser projects.

Takeaway on codebase scale: On a 16-project repository, an agent with ripgrep does not miss callers—it simply needs ~2× more turns (for example, running follow-up searches when discovering that parser classes implement ISemanticExtension transitively through IComponentLibraryParser, ILibraryParser, or abstract base classes like CSharpLibraryParserBase). The accuracy gap between lexical search and a semantic graph emerges on large monorepos like Case Study 01 (24,527 files) and Case Study 02 (324 services).
