Takeaway on codebase scale: On a 16-project repository, an agent with ripgrep does not miss callers—it simply needs ~2× more turns (for example, running two sequential searches when discovering that 62 language library parsers inherit from abstract base classes like GoLibraryParserBase rather than implementing ILanguageLibraryParser directly). The accuracy gap between lexical search and a semantic graph emerges on large monorepos like Case Study 01 (24,527 files) and Case Study 02 (324 services).
