# CodeExplorer.Parser.Rust

Rust Cargo crate and AST parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.Rust` provides Cargo workspace and crate boundary detection (`Cargo.toml`), Tree-sitter Rust AST extraction, and semantic extensions for Actix Web, Axum, Rocket, Tonic (gRPC), SQLx, Diesel, SeaORM, Reqwest, and Tokio.

## Installation

```bash
dotnet add package CodeExplorer.Parser.Rust
```
