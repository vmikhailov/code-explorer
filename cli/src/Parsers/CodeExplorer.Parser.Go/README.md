# CodeExplorer.Parser.Go

Go module and AST parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.Go` provides Go module boundary detection (`go.mod`, `go.work`), Tree-sitter Go AST extraction, and semantic extensions for Gin, Echo, Fiber, Chi, `net/http`, gRPC-Go, GORM, `sqlx`, `database/sql`, and Kafka/Redis clients.

## Installation

```bash
dotnet add package CodeExplorer.Parser.Go
```
