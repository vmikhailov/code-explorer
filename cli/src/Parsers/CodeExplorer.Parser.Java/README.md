# CodeExplorer.Parser.Java

Java Maven/Gradle project and AST parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.Java` provides Maven and Gradle project detection (`pom.xml`, `build.gradle`, `build.gradle.kts`), Tree-sitter Java AST extraction, and semantic extensions for Spring Boot, Jakarta EE / JAX-RS, Micronaut, Quarkus, Hibernate / JPA, Spring Data, JDBC, Feign, RestTemplate, WebClient, and Kafka/RabbitMQ clients.

## Installation

```bash
dotnet add package CodeExplorer.Parser.Java
```
