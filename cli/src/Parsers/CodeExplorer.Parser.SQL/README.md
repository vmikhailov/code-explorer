# CodeExplorer.Parser.SQL

SQL schema, DDL/DML, and stored procedure parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.SQL` provides Tree-sitter SQL AST extraction, table/view/procedure declaration indexing, and data lineage extraction (`READ`, `INSERT`, `UPDATE`, `DELETE`, `DDL`) across SQL scripts and database migration projects.

## Installation

```bash
dotnet add package CodeExplorer.Parser.SQL
```
