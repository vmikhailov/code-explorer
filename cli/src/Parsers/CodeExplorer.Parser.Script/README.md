# CodeExplorer.Parser.Script

Shell, PowerShell, Batch, and automation script parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.Script` indexes shell scripts (`.sh`, `.bash`), PowerShell scripts (`.ps1`, `.psm1`), and Windows batch/command scripts (`.cmd`, `.bat`), extracting functions, CLI invocations, and cross-script execution dependencies.

## Installation

```bash
dotnet add package CodeExplorer.Parser.Script
```
