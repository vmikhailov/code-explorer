# CodeExplorer.Parser.Python

Python project/AST parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.Python` provides Python project and dependency detection (`pyproject.toml`, `requirements.txt`, `setup.py`), Tree-sitter Python AST extraction, and semantic extensions for FastAPI, Flask, Django, SQLAlchemy, Tortoise ORM, Peewee, Celery, Requests, HTTPX, Boto3, and Redis/PostgreSQL drivers.

## Installation

```bash
dotnet add package CodeExplorer.Parser.Python
```
