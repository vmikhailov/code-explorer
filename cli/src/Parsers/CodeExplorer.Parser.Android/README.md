# CodeExplorer.Parser.Android

Android project manifest and resource parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.Android` detects Android application and library modules (`AndroidManifest.xml`, Gradle Android plugins), indexing activities, services, broadcast receivers, content providers, permissions, and deep-link intent filters.

## Installation

```bash
dotnet add package CodeExplorer.Parser.Android
```
