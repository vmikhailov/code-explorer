# CodeExplorer.Parser.Shared

Shared parser utilities, configuration and manifest enrichers, and cross-language semantic helpers for [CodeExplorer](https://github.com/vmikhailov/code-explorer) language plug-ins.

## Overview

`CodeExplorer.Parser.Shared` provides common infrastructure shared across all CodeExplorer language parsers, including configuration file parsers (`.env`, `appsettings.json`, YAML, TOML, `.properties`, Docker Compose), route normalization, and AST visitor base utilities.

## Installation

```bash
dotnet add package CodeExplorer.Parser.Shared
```
