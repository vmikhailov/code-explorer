# CodeExplorer.Parser.CSharp

C# and .NET project/AST parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.CSharp` provides MSBuild/NuGet project boundary detection (`.csproj`, `Directory.Build.props`, `Directory.Packages.props`), Tree-sitter C# AST extraction, and semantic library extensions for ASP.NET Core, Entity Framework Core, Dapper, gRPC, HotChocolate GraphQL, MassTransit, MediatR, HttpClient, Refit, RestSharp, and Redis/SQL/NoSQL drivers.

## Installation

```bash
dotnet add package CodeExplorer.Parser.CSharp
```
