# CodeExplorer.Parser.TypeScript

TypeScript and JavaScript project/AST parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.TypeScript` provides Node.js/TypeScript workspace and package boundary detection (`package.json`, `tsconfig.json`), Tree-sitter TypeScript/TSX/JavaScript AST extraction, and semantic extensions for NestJS, Express, Fastify, Next.js, React, Angular, TypeORM, Prisma, Drizzle, Sequelize, Mongoose, Axios, Fetch, and gRPC/GraphQL clients.

## Installation

```bash
dotnet add package CodeExplorer.Parser.TypeScript
```
