# CodeExplorer.Parser.Kotlin

Kotlin Gradle/Maven project and AST parser plug-in for [CodeExplorer](https://github.com/vmikhailov/code-explorer).

## Overview

`CodeExplorer.Parser.Kotlin` provides Kotlin project boundary detection (`build.gradle.kts`, `build.gradle`, `pom.xml`), Tree-sitter Kotlin AST extraction, and semantic extensions for Ktor, Spring Boot, Exposed, Room, Retrofit, OkHttp, and Koin/Hilt.

## Installation

```bash
dotnet add package CodeExplorer.Parser.Kotlin
```
